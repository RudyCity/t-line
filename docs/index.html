Developer Setup & Build from Source

Prerequisites: Bun 1.1+ (or Node 20+), Git, and Rust (for Tauri desktop builds).

# 1. Clone repository
git clone https://github.com/RudyCity/t-line.git
cd t-line

# 2. Install workspace dependencies with Bun
bun install

# 3. Run Express backend & React UI concurrently
bun dev
1
Clones repository and installs all workspace packages using Bun.
2
Spawns Express backend (Port 3999) and Vite React client with auto-proxy to SuperAgent port 7888.
# 1. Launch SuperAgent server engine on port 7888
bunx superagent --server --multi

# 2. t-line auto-detects and connects via superAgentBridge.ts
# Express REST proxy available at: http://localhost:3999/api/superagent/*
1
Starts SuperAgent HTTP/SSE server engine on port 7888.
2
t-line automatically proxies all 45+ endpoints, syncs RMemory, and displays real-time agent execution trees.
# Launch Tauri native client in development mode
bun run tauri
1
Compiles and loads the Rust native Tauri v2 desktop application.
2
Registers system tray menus, locks port 5773, and hooks native PTY shells.
# Package standalone desktop installers (.exe, .msi, .dmg, .AppImage)
bun run build:tauri
1
Builds production bundles for the React frontend and Express backend.
2
Packages native desktop installers for Windows, macOS, and Linux. Artifacts output to `desktop-tauri/src-tauri/target/release/bundle/`.
